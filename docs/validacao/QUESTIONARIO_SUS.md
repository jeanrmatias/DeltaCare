## Como calcular (para a equipe, não para o participante)

As afirmações ímpares são positivas e as pares, negativas, por isso a conta
inverte as pares:

1. **Ímpares (1, 3, 5, 7, 9):** resposta − 1.
2. **Pares (2, 4, 6, 8, 10):** 5 − resposta.
3. Some os dez valores (dá de 0 a 40) e **multiplique por 2,5**. A nota vai de
   0 a 100.

**Exemplo:** respostas 4, 2, 5, 1, 4, 2, 4, 1, 4, 2.
Ímpares: 3 + 4 + 3 + 3 + 3 = 16. Pares: 3 + 4 + 3 + 4 + 3 = 17.
(16 + 17) × 2,5 = **82,5**.

**Como ler:** a nota **não é porcentagem**. A média de referência, de
centenas de estudos, fica perto de **68**: acima disso, melhor que a média;
abaixo de 50, sinal de problema sério. Com três participantes, olhe a nota de
cada um junto com a ficha dele — uma nota baixa explicada por uma tarefa
travada diz mais que a média das três.
